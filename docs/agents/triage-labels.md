# Triage labels

Use these mappings whenever an engineering skill names a canonical triage role.

| Canonical role    | GitHub label      | Meaning                                      |
| ----------------- | ----------------- | -------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate the issue       |
| `needs-info`      | `needs-info`      | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent       |
| `ready-for-human` | `ready-for-human` | Requires human implementation                |
| `wontfix`         | `wontfix`         | Will not be actioned                         |

For triage behavior and transitions, read `.agents/skills/triage/SKILL.md`. Keep repository-specific label overrides in this table.
